## Description du Projet
« AutoLoc » est une plateforme de gestion de location de véhicules multi-agences développée avec Spring Boot, Spring Data JPA et MySQL.
Ce dépôt contient le travail complet et incrémental des 5 ateliers :
1. **Atelier 1 (Chapitre 1)** : Configuration de l'environnement (JDK 17, IntelliJ IDEA, MySQL autoloc_db, Git).
2. **Atelier 2 (Chapitre 2)** : Création du projet Spring Boot / Maven et entités JPA sans associations.
3. **Atelier 3 (Chapitre 3 / Chapitre 2 suite)** : Mapping des associations relationnelles (Cascade, Fetch, Relations bidirectionnelles) et tests.
4. **Atelier 4 (Chapitre 4)** : Couche Repository Spring Data JPA, pagination et tri.
5. **Atelier 5 (Chapitre 5)** : Architecture IoC / DI, services génériques et implémentations métier.
